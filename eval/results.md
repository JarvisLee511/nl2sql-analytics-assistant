# NL→SQL benchmark

13 natural-language questions → SQL, generated by each model and executed against the 1.16M-row warehouse. **Correctness is judged by an independent model (claude-opus-4-8)** against hand-verified gold SQL, accepting reasonable variation (columns, rounding, sort, metric definition).

> **Run 2026-06-24.** These were the current Claude models on that date. Scores are point-in-time — re-running against newer models will produce different numbers.

| Model | Valid SQL | Correct (LLM-judged) |
|---|---|---|
| `claude-opus-4-8` | 13/13 (100%) | **9/13 (69%)** |
| `claude-sonnet-4-6` | 12/13 (92%) | **9/13 (69%)** |
| `claude-haiku-4-5` | 11/13 (85%) | **5/13 (38%)** |
